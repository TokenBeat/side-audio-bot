# 晚晴 · WanQing

> 天意怜幽草，人间重晚晴。——李商隐

**晚晴**是基于 qwen-audio-agent 实时语音框架打造的智慧康养产品系列，面向"晚年晴好"这一愿景，让每一位老人都有一个听得懂方言、记得住习惯、叫得应人、靠得住的语音伙伴。

本项目与仓库内 `examples/smart-cockpit`（智能座舱示例）同一架构范式：**框架核心 + 垂直场景产品**。座舱证明了这套框架能撑起一个真实业务场景，晚晴把同样的能力带进康养。

## 两个垂直产品

| | 晚晴·照护（机构版） | 晚晴伴（居家版） |
| --- | --- | --- |
| 面向 | 养老院、护理院、日间照料中心 | 独居老人、子女不在身边的家庭 |
| 付费方 | 机构（效率 + 服务品质） | 子女（安心 + 陪伴） |
| 核心价值 | 呼叫有人接、状态看得见、文书省时间 | 每天有人问、有事找得应、子女放得心 |
| 形态 | 机构内网本地部署：房间终端 + 护理站大屏 + 护理员 App + 家属端 | 家庭网关：老人端 + 家属手机端 |
| 隐私叙事 | 数据不出院（本地 s2s 可选） | 数据不出家门（家庭网关 + Tailscale） |

## 开发约定

- 只消费框架公开边界（`qwen-audio-agent/*` 导出、MemoryProvider、GCP 协议、设备凭证），不复制框架内部实现（与座舱同一纪律）
- 代码在 `product/wanqing` 分支上开发，**不进 dev**——dev 的任何提交都会在下一次发版时被打进公开的 public 分支
- 演示语音链路默认 DashScope 实时（稳定、已验证）；本地 s2s 作为部署叙事与第二阶段选项
