# 01 · 命名与品牌

## 命名体系

| 层级 | 名称 | 出处 / 寓意 |
| --- | --- | --- |
| 项目总名 | **晚晴**（WanQing） | 李商隐《晚晴》："天意怜幽草，人间重晚晴"。久雨转晴、晚年晴好——不回避衰老，但强调被照护之后的从容与明亮 |
| 机构版 | **晚晴·照护**（WanQing Care） | 面向机构，"照护"直指 B2B 场景的专业与责任 |
| 居家版 | **晚晴伴**（WanQing Companion） | 面向家庭，"伴"是陪伴，也是老伴的伴——独居老人最缺的那个字 |

英文/拼音标识：`WanQing`、`wanqing-care`、`wanqing-companion`。App/包名占位：`care.wanqing.app`、`home.wanqing.app`。

## 品牌调性

**三个关键词：温暖、笃定、不啰嗦。**

- 温暖：老人愿意跟它说话。文案不卖弄智能，像一位耐心的晚辈
- 笃定：护理员敢依赖它。状态、工单、时间，说一是一
- 不啰嗦：语音回复短句优先，界面一屏一事，绝不堆功能

## 视觉语言（与座舱的差异）

座舱是"科技座驾"：深底、冷光、3D 车模。晚晴反着来：

| 维度 | 晚晴设计语言 | 理由 |
| --- | --- | --- |
| 底色 | 暖米白（老人端）/ 深暖灰（大屏） | 老年性黄斑病变对深底高对比更友好；暖色传递"家"而非"设备" |
| 主色 | 晨光橙 `#E8722A`（行动/品牌）、常青绿 `#3E7C5B`（正常态） | 暖橙是清晨阳光的颜色；绿=平安，红=呼叫，琥珀=提醒，三色语义全产品一致 |
| 字号 | 老人端正文 ≥22px、标题 ≥34px、按钮文字 ≥24px | 70 岁平均视力约为年轻人的 1/3；大屏按 3 米观看距离设计，数字 ≥48px |
| 触达 | 所有可点目标 ≥72px，间距 ≥16px | 手部震颤、精细动作退化 |
| 编码 | 图标 + 文字 + 颜色三重编码 | 不依赖单一感官 |
| 动效 | 慢呼吸圈（语音态）、克制淡入 | 快速闪烁会引起焦虑；语音状态用"呼吸"隐喻 |
| 声音 | 唤醒音 2 个柔和音符；提醒前奏固定旋律 | 用听觉建立条件反射，老人视力不等时也能用 |

## 文案守则

1. 称呼用"您"，不带机构术语（不说"工单"，对老人说"已经告诉护理员了"）
2. 语音回复默认 ≤2 句；提醒类必须带具体时间（"您 4 点的降压药，还有 10 分钟"）
3. 错误话术不出现"失败/错误"，说"没说清楚，您再说一遍好吗"
4. 所有面向老人的文案，护理站/家属端有对应的专业表述
