# 02 · 需求总览

两个垂直产品的需求清单。优先级：**P0 = 今晚演示必备**，P1 = 打磨期，P2 = 二期。

调研依据（2025-09）：养老机构 AI 语音记录使早班文书时间 -28%（蓝鲸）；老人语音语调可预测抑郁风险达筛查级准确率（AgeClub）；现有智能音箱为反应式、2-3 轮退化、无记忆无升级链路（新浪/知乎实测）；医院大模型落地难在 HIS 集成与幻觉责任（证券时报/清华）。晚晴的对位：**主动式（问安/提醒）、有记忆、有升级链路、可私有化、懂方言**。

## 一、共享核心（框架直接提供）

| 能力 | 来源 | 两版用法 |
| --- | --- | --- |
| 全双工实时语音 + 自然打断 | GCP / 实时前台 | 所有语音交互 |
| 前台/后台域路由 | surface routing | 娱乐问答走前台；呼叫/SOS/用药确认走后台 |
| 记忆引擎 | VoiceMem / MemoryProvider | 老人偏好、用药、习惯、家属称呼 |
| 周期提醒 | recurring reminders | 吃药、复诊、翻身、问安排期 |
| 设备凭证 + 客户端接管 | gateway pair / revoke | 终端/手机配对，家属端接入 |
| 本地 s2s | STT+LLM+TTS 全本地 | 机构"数据不出院"、居家"数据不出家门"（部署叙事） |
| 状态投影 | SSE（座舱模式） | 护理站大屏 / 家属端状态页 |

## 二、晚晴·照护（机构版）P0

### 老人侧 · 房间终端
- [ ] P0 全屏语音对话：按住说话或免唤醒连续对话，大字转写，呼吸圈状态
- [ ] P0 用药提醒：到期终端主动响铃 + 语音播报，老人口头确认（"吃了"）→ 写回状态
- [ ] P0 一键呼叫：物理大按钮 + 语音"我要喝水/疼/上厕所"均可触发 → 生成呼叫工单 → 大屏与护理员端同步，终端显示"已通知护理员，X 分钟内到"
- [ ] P0 生活问答/娱乐：天气、戏曲广播、聊天（走前台）
- [ ] P1 日常聊天带记忆（偏好/家属称呼/禁忌）
- [ ] P1 活动报名（"下午三点的手工课帮我报上"）
- [ ] P2 家属留言播放、视频通话

### 护理站 · 大屏
- [ ] P0 房间/床位网格：四态着色（平安绿 / 呼叫红闪 / 提醒琥珀 / 离线灰），3 米可读
- [ ] P0 呼叫队列：按等待时长排序、响应倒计时、点击受理
- [ ] P0 SSE 实时刷新（状态、工单、提醒事件）
- [ ] P1 提醒到期列（谁该翻身/吃药）、在岗护理员、交接班摘要
- [ ] P1 响应统计（平均响应时长、今日呼叫数）
- [ ] P2 与床垫/穿戴数据联动

### 护理员侧
- [ ] P0 工单接收与受理（Web 卡片流，模拟 App）
- [ ] P1 语音交班记录（语音→结构化交班摘要）
- [ ] P2 排班管理

### 后台 Agent（工单编排）
- [ ] P0 呼叫→工单→派单给当班护理员→超时未受理升级护士长（状态机）
- [ ] P1 用药确认回写、活动报名执行

**机构 MVP 演示闭环**：老人说"我要喝水" → 大屏变红闪 → 工单派单 → 护理员受理 → 大屏转"处理中" → 完成回绿。全程 ≤10 秒。

## 三、晚晴伴（居家版）P0

### 老人侧 · 老人端
- [ ] P0 全屏语音对话（同机构版交互规范）
- [ ] P0 用药/作息提醒（主动响铃 + 口头确认）
- [ ] P0 SOS 一键呼救：大按钮 + 语音触发 → 升级链路启动 → 终端全程显示"已通知女儿"
- [ ] P0 日常聊天带记忆
- [ ] P1 家人留言（子女从家属端发语音，终端播放）
- [ ] P2 声学异常感知（长时间无语音、情绪异常）

### 家属侧 · 家属端
- [ ] P0 老人状态卡：今天问安 ✓、最近一次对话时间、心情、提醒完成情况
- [ ] P0 通知中心：SOS、问安无应答、提醒未确认
- [ ] P0 远程对话入口（点击后与老人终端建立语音，演示用同屏模拟）
- [ ] P1 留言、用药计划远程调整、周报

### 系统侧
- [ ] P0 问安调度：定时任务 → 主动发起语音问安 → 结果写状态 → 无应答触发升级
- [ ] P0 升级链路状态机：SOS/无应答 → 通知家属（一级）→ 备用联系人（二级）→ 演示级联
- [ ] P2 电话外呼（SIP）、社区/急救接口

**居家 MVP 演示闭环**：上午 9 点终端主动响起问安 → 老人应答聊天（记得昨天说腰疼）→ 状态卡更新家属可见；老人按 SOS → 家属端弹窗 + 终端显示"已通知女儿"。
