# 04 · 晚晴伴（居家版）产品设计

## 角色与界面清单

| 角色 | 界面 | 路由 | 设备形态 |
| --- | --- | --- | --- |
| 老人 | 老人端 | `/elder` | 客厅音箱/平板，或旧手机改的床头终端 |
| 子女 | 家属端 | `/family` | 手机浏览器（PWA 就绪） |
| 系统 | 问安调度（无界面） | — | 后台定时任务 |

与机构版共用交互规范与视觉语言（见 03 文档），差异只在信息密度与升级链路。

## 一、老人端

### 布局（同房间终端骨架，去掉机构元素）

```
┌──────────────────────────────┐
│  09:00   9月13日 周六         │
│                              │
│      ╭──────────────╮        │
│      │   呼吸圈/头像  │        │
│      ╰──────────────╯        │
│   「张阿姨，早上好」           │
│   今天记得吃降压药哦           │
│                              │
│  ┌─────────┐  ┌─────────┐    │
│  │  💊     │  │  🆘     │    │  ← SOS 红色大按钮，长按 1.5s 防误触
│  │ 8点药 ✓ │  │ 紧急求助 │    │
│  └─────────┘  └─────────┘    │
│  ┌──────────────────────┐    │
│  │ 🎵 女儿的留言 ▶ 00:23 │    │  ← 家属留言卡（P1）
│  └──────────────────────┘    │
│  最近的话：跟它聊了腰疼的事…    │
└──────────────────────────────┘
```

### 关键交互

1. **主动问安**（本产品的灵魂，座舱没有的东西）：
   - 到点终端柔铃 3 声 → 全屏问安卡"早上好呀，睡得好吗" → 免唤醒直接对话
   - 老人应答 ≥2 轮 → 问安完成，写状态（应答/心情标签/提到的事）
   - 铃响 60 秒无应答 → 视为未接，进入升级链路（先再等 5 分钟重拨一次，仍无应答通知家属）
2. **SOS 升级链路**（全程可视化安抚）：
   - 触发（长按按钮 / 说"救命/我不舒服"）→ 终端："别急，我马上通知小雨" → 家属端强提醒（红幅+震动音）
   - 家属端 30 秒不响应 → 终端"再通知小林"（二联系人）→ P2 电话外呼
   - 状态三段回投：已通知 → 对方已看到 → 对方正在赶来（家属端点按回执）
3. **记忆感**：问安与闲聊引用记忆（"昨天说腰疼，今天好点没"）——记忆引擎自动沉淀
4. **提醒**：同机构版用药流；家属端可远程增改（P1）

## 二、家属端（子女每天看的界面）

### 布局（手机竖屏，单手可达）

```
┌────────────────────────┐
│ 晚晴伴      我 · 妈妈的  │  ← 顶部老人切换（P2 多老人）
├────────────────────────┤
│ ╭────────────────────╮ │
│ │ 张秀兰  78岁  ♥ 平安 │ │  ← 状态大卡（SSE 实时）
│ │ 今早 9:00 问安 ✓     │ │
│ │ 心情：不错 · 聊了腰疼 │ │
│ │ 💊 早药已确认 08:12  │ │
│ │ 上次对话 14:32       │ │
│ ╰────────────────────╯ │
│ ┌────────────────────┐ │
│ │ 📞 跟妈妈说说话      │ │  ← 远程对话（一期同屏模拟）
│ └────────────────────┘ │
│ 通知                    │
│ ● 09:00 问安完成 ✓      │
│ ● 08:12 用药确认        │
│ （SOS/未应答在此强提醒）  │
└────────────────────────┘
```

### 关键交互

1. 状态卡是"安心"的落点：平安绿常亮；异常时整卡转红 + 顶部横幅
2. 通知分级：SOS/未应答=强提醒（声音+震动+红幅），常规=静默列表
3. 远程对话：点 [跟妈妈说说话] → 家属端麦克风采集 → 老人终端播放并回传（一期与老人端同屏模拟双向，二期走移动端真机）
4. 留言：按住说话 → 终端收到"女儿的留言"卡片（P1）

## 三、系统侧（无界面）

- **问安调度器**（service 内）：cron 触发 → 创建问安任务 → 走后台 Agent 发起终端会话（终端自动接听免唤醒）→ 汇总结果
- **升级链路状态机**：

```
触发(SOS | 问安无应答)
  → 通知一级联系人（家属端强提醒 + 终端播报"已通知"）
      ├─ 30s 内确认 → 终端回投"女儿看到了" → 结束
      └─ 30s 未确认 → 通知二级联系人 → （P2 电话外呼）→ 记录全程时间线
```

- 全程时间线落状态存储：家属端可回看"从呼救到响应"的每一秒（信任的来源）

## 四、语音域路由

| 域 | 走向 |
| --- | --- |
| SOS / 求助 | 后台（升级链路 Agent） |
| 问安（系统发起） | 后台（调度器 + Agent） |
| 提醒确认 | 后台（写状态） |
| 天气/闲聊/记忆问答 | 前台 |
| 媒体（戏曲/留言） | 前台 |

## 五、演示脚本（录视频用，约 3 分钟）

1. 开场：家属端状态卡（昨天数据：问安 ✓、心情不错）5 秒
2. 切老人端：9:00 问安自动响起 → 老人应答"还行，腰有点酸" → 它接住："昨天也提过腰疼，今天别老坐着，要不要我提醒你起来走走"（记忆亮点）
3. 问安完成 → 切家属端：状态卡已更新（09:02 问安 ✓ · 提到腰疼）
4. 老人按 SOS → 终端"已通知小雨" → 家属端红幅强提醒 → 点确认 → 终端"小雨已经看到了"
5. 结尾：字幕——"数据不出家门：语音在家庭网关本地处理，只有问安摘要到女儿手机"
