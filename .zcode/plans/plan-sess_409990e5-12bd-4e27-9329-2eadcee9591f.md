# side-audio-bot 场景分析 + 种子轮 BP 大纲 计划

## 已确认的项目事实（分析基础）
- 车机示例 = `examples/smart-cockpit`（智能座舱，约 1 万行完整可跑：3D 车模 + 高德导航 + 车控 + 音乐 + 闪购 + 语音创建技能 + 人设热切换）
- 现成积木：全双工语音前台（DashScope/StepFun/纯本地 s2s）、本地唤醒词、Electron 悬浮球 + Bloub 宠物外观、记忆/个性化、任务派工（spawn_thinking → 12 种后台 Agent）、MCP/OpenAPI 工具接入、品牌层换皮机制
- 短板：无移动端/嵌入式，Gateway 仅本地部署
- 仓库是公开开源仓库（当前 public 分支）→ **融资材料必须放仓库外**

## 交付物（新建 `~/repos/side-audio-bot-pitch/` 目录）

### 1. `01-场景分析报告.md`
6 个候选场景，每个包含：一句话定位 / 为什么适合本项目（映射到具体代码资产）/ 改造清单与工作量估计 / 市场规模与政策 / 竞争格局 / 融资故事强度评分 / 主要风险：
- **银发居家养老语音管家**（用户指定重点：提醒/用药/家属通知/紧急呼叫工具包，替换 smart-cockpit 的车控工具包，B2G 民政采购 + C 端子女订阅双模式）
- AI 陪伴/情感精灵（悬浮球+桌宠现成，赛道最热）
- 智能座舱方案商（现有 demo 直接当销售演示）
- 酒店客房语音管家（仿 smart-cockpit 四进程结构换客控工具）
- 全屋智能语音中枢（接 Home Assistant MCP）
- 儿童教育陪伴（合规成本高，作为对照项）
结尾：对比总表 + 推荐排序（预期银发养老为主线，若分析结论不同会如实说明）

### 2. `02-BP大纲.md`（种子轮、个人项目定位）
10-15 节大纲，每节带要点提示和数据占位：问题 → 方案 → 为什么是现在 → 产品与技术壁垒（基于真实代码事实，经得起技术尽调）→ 市场与政策 → 商业模式（B2G+B2C）→ 竞争与差异化 → MVP 路线图（基于改造清单排期）→ 团队与互补需求（个人项目如实写，列需要补的合伙人画像）→ 融资需求与资金用途 → 里程碑与风险。另附「见投资人前的准备动作清单」（含修 README 过期的 examples/car 引用等 repo 卫生项）
