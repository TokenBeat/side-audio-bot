# Side Audio Bot v0.11.1 · 模型选项与悬浮球彩蛋 / New Model Option & Orb Easter Eggs

v0.11.1 新增 **StepFun stepaudio-2.5-realtime 模型选项**（仅前台语音），并修复 **Bloub 悬浮球皮肤的彩蛋动画**。

v0.11.1 adds a new **StepFun stepaudio-2.5-realtime model option** (front-end voice only) and fixes the **Bloub orb skin easter-egg animations**.

---

## ✨ 本版更新 / What's New

### 🎙️ StepFun 新增 stepaudio-2.5-realtime / New stepaudio-2.5-realtime Option

- **模型列表新增 stepaudio-2.5-realtime**：标注为「仅前台语音」——该模型暂不支持工具调用，适合纯语音对话场景。
  **stepaudio-2.5-realtime joins the model list**, labeled "front-end voice only" — it does not support tool calls yet, making it a fit for pure voice conversations.
- **默认配置不变**：默认模型保持 step-audio-2，既有用户无需任何调整。
  **No default changes**: the default model stays step-audio-2 — existing users need no adjustment.

### 🎨 Bloub 彩蛋修复 / Bloub Easter-Egg Fixes

- **唤醒孵化动画恢复**：唤醒瞬间悬浮球先从蛋中孵化，再进入日常表情。
  **Wake-up hatch restored**: on wake, the orb hatches from its egg before settling into its regular look.
- **庆祝与周期彩蛋**：悬停与任务完成播放爆开庆祝，工作期间穿插六边形周期彩蛋。
  **Burst and periodic easter eggs**: hover and task completion trigger burst celebrations, with hexagon treats during work sessions.
- **彩蛋节奏对齐状态机**：每段彩蛋播放完整时长后再交还状态机，过渡不再突兀。
  **Easter-egg timing aligned with the state machine**: each animation plays out in full before handing control back.
