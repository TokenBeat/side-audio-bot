# Side Audio Bot v0.11.0 · 首个公开发布 / First Public Release

Side Audio Bot 是 [qwen-audio-agent](https://github.com/QwenLM/qwen-audio-agent) 的深度定制发行版：品牌、文档与发行物完全独立，同时保持与上游的可合并性。本版本基于上游 v1.11.0 代码基线。

Side Audio Bot is a curated distribution of [qwen-audio-agent](https://github.com/QwenLM/qwen-audio-agent) — fully rebranded docs and artifacts while staying mergeable with upstream. This release is based on the upstream v1.11.0 code baseline.

---

## ✨ 本版新特性 / What's New

### 🎨 Bloub 悬浮球外观 / Bloub Orb Skin

- **全新 Bloub 机器人悬浮球皮肤**：为桌面悬浮球新增 Bloub 形态，形态、配色与表情可独立定制，让助手拥有自己的"性格"。
  **Brand-new Bloub bot orb skin** for the desktop floating ball — independently customizable shape, palette and expressions give your assistant a personality of its own.
- **外观设置热更新**：调整形态与颜色即时生效，无需重启应用。
  **Appearance changes hot-apply instantly** — no restart required.
- **全栈交互与多语言打磨**：中英文案、外观选项持久化、渲染时序修复一应俱全。
  **Full-stack i18n and interaction polish**: zh/en copy, persisted appearance options and render-timing fixes.

### 🎙️ StepFun StepAudio 实时语音 / StepFun StepAudio Realtime Voice

- **新增阶跃星辰 StepFun StepAudio 实时语音前台**：在设置中选择 StepFun 前台并填入 API Key 即可使用。
  **Adds the StepFun StepAudio realtime voice frontend** — pick StepFun in Settings and provide your API key to get started.
- **与内置 DashScope 前台并存**：两套前台共用统一的会话、权限与记忆管线，可按需切换。
  **Coexists with the built-in DashScope frontend**: both share the unified session, permission and memory pipelines, switchable at any time.
- **配置方式与上游标准一致**：通过既有的环境变量 / 设置界面完成凭证配置。
  **Configuration follows the established conventions**: credentials via the standard env vars / settings UI.

> **macOS 未签名说明 / Unsigned macOS build**：本 DMG 未做 Developer ID 签名与公证。首次打开请**右键 App →「打开」**，或在终端执行：
> The DMG is not signed or notarized. On first launch, **right-click the app → Open**, or run in a terminal:
>
> ```sh
> xattr -cr "/Applications/Side Audio Bot.app"
> ```

> **Windows SmartScreen**：安装包未签名，SmartScreen 提示时选择「更多信息 → 仍要运行」即可。
> The installer is unsigned; when SmartScreen warns, choose "More info → Run anyway".

### 安装方式 / Install

- **macOS**：打开 DMG，将 Side Audio Bot 拖入 Applications。
  Open the DMG and drag Side Audio Bot into Applications.
- **Windows**：运行安装程序，按提示完成安装（可选安装目录）。
  Run the NSIS installer and follow the prompts (custom install directory supported).

## 🔄 自动更新 / Auto Update

桌面端内置 electron-updater，更新元数据（`latest-mac.yml` / `latest.yml`）随本 Release 一并发布。后续版本发出后，应用内会自动检测并提示更新。

The desktop app ships with electron-updater; update metadata (`latest-mac.yml` / `latest.yml`) is published alongside this release. Future releases will be detected and offered in-app automatically.
