# Side Audio Bot v0.11.2 · StepFun Audio3 前台语音与 Bloub 外观优化 / StepFun Audio3 Voice & Bloub Appearance Polish

v0.11.2 为前台语音新增 **StepFun Audio 3 Realtime**（stepaudio-3-realtime-preview）支持，并优化 **Bloub 悬浮球的外观设置体验**。

v0.11.2 adds **StepFun Audio 3 Realtime** (stepaudio-3-realtime-preview) support for front-end voice and polishes the **Bloub orb appearance settings experience**.

---

## ✨ 本版更新 / What's New

### 🎙️ StepFun Audio 3 Realtime 前台语音 / New StepFun Audio 3 Realtime Voice

- **前台语音新增 StepFun Audio 3 Realtime**：默认模型 stepaudio-3-realtime-preview，接入 StepFun 开放平台 Realtime 接口，在设置中即可切换为语音前台。
  **StepFun Audio 3 Realtime joins the front-end voice line-up**: the default model is stepaudio-3-realtime-preview, served through StepFun's Realtime API and selectable from settings.
- **实时语音设置表单统一重构**：各语音前台的模型、声音等选项收敛到统一的实时设置表单，后续新增前台无需再各写一套界面。
  **Unified realtime settings form**: model and voice options for every voice frontend now live in one unified form, so future frontends no longer need bespoke UI.
- **新增 StepFun 配置文档**：`docs/voice-frontends/stepfun.md` 覆盖开通、鉴权与前台切换步骤。
  **New StepFun docs**: `docs/voice-frontends/stepfun.md` covers account setup, credentials, and frontend switching.

### 🎨 Bloub 外观设置优化 / Bloub Appearance Settings Polish

- **外观配置融入统一设置表单**：Bloub 皮肤与外观选项随实时语音设置一并收纳，设置入口更清爽。
  **Appearance options folded into the unified form**: Bloub skin and appearance options now live alongside the realtime voice settings for a cleaner settings entry.
- **修复动态选项语言渲染**：设置页的动态选项现在按当前生效语言渲染，切换语言立即生效。
  **Fixed dynamic-option language rendering**: dynamic options on the settings page now render in the active language and refresh immediately on switch.
- **修复应用按钮不亮**：外观控件的改动正确纳入变更监听，修改后应用按钮正常点亮。
  **Fixed dim Apply button**: appearance controls are now wired into the change listener, so the Apply button lights up as soon as you edit.
