# Side Audio Bot v0.11.3 · 稳定性修复 / Stability & Fixes

v0.11.3 是一次稳定性修复版本：实时语音在工具调用后的响应更跟手，桌面端对话面板与设置更可靠，并修复了 Windows 路径与网关层面的一批问题。

v0.11.3 is a stability release: realtime voice responds more promptly after tool calls, the desktop conversation panel and settings are more reliable, and a batch of Windows-path and gateway issues is fixed.

---

## ✨ 本版更新 / What's New

### 🎙️ 实时语音 / Realtime Voice

- **工具结果即时播报**：Agent 执行工具后，结果立即送回语音对话，不再等待整轮对话结束才输出。
  **Tool results are delivered immediately**: after the Agent runs a tool, the result now flows straight back into the voice conversation instead of waiting for the turn to finish.

### 🖥️ 桌面端 / Desktop

- **对话面板定位最新消息**：打开对话面板时自动定位到最新一条消息，无需手动翻找。
  **Conversation panel opens at the latest message**: the panel now opens right where the conversation ends, no manual scrolling.
- **保留自定义 ACP 配置**：设置中配置的通用 ACP 后端在重启后不再丢失。
  **Generic ACP settings persist**: custom ACP backends configured in settings no longer disappear after a restart.

### 🔧 Agent 与网关 / Agent & Gateway

- **MCP 工具完整发现**：修复工具列表只读取第一页的问题，多页 MCP 工具现在都能被发现。
  **Full MCP tool discovery**: fixed tool discovery reading only the first page — paginated MCP tool lists are now fully loaded.
- **网关错误隔离与资源上限**：异常客户端的协议错误被隔离在各自会话内；音频/控制发送缓冲与会话日志、缓存写入都设有上限，避免长时间运行下的内存无界增长。
  **Gateway error isolation & bounded resources**: malformed client errors stay confined to their own session; audio/control send buffers, session journals and caches are bounded to prevent unbounded memory growth.

### 🪟 Windows / Windows

- **修复路径含空格的一系列问题**：安装目录、后端探测、Skills（npx）启动、批处理命令引用、登录状态读取等在含空格路径下不再失败。
  **Fixes for paths with spaces**: backend install & probing, Skills (npx) launch, batch command quoting, and login-status reading no longer fail when the install path contains spaces.

- **macOS**：打开 DMG，将 Side Audio Bot 拖入 Applications。

  Run the NSIS installer and follow the prompts (custom install directory supported).

## 🔄 自动更新 / Auto Update

桌面端内置 electron-updater，更新元数据（`latest-mac.yml` / `latest.yml`）随本 Release 一并发布。从 v0.11.2 升级可在应用内直接检测并提示更新。

The desktop app ships with electron-updater; update metadata (`latest-mac.yml` / `latest.yml`) is published alongside this release. Users on v0.11.2 will be offered this update in-app automatically.
